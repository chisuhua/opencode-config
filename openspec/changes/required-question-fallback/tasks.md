## 已知边界（写进测试注释 / 观察报告，不假装覆盖）

- **覆盖面「漏登记」不可机械核**（design D1）⇒ 清单是**单源** ⇒ 新增「必须问」之节若未登记 ⇒ 该节无兜底
  ⇒ 靠**登记义务 + §自查清单 + 评审**发现（AC13 ②）；粗扫 alarm **可延后**（backlog）。
- **E-7 的「是否自行假设」语义负向未覆盖**（design D5）⇒ 只做 transcript 事实 + 正向断言（AC13 ③）。
- **层 2 的 timeout 不等于 fail**（design D8）⇒ 取证不可用 ⇒ 记为「未判定」（AC11）。
- **`question` 的运行期失败形态**不止 `status == "error"` ⇒ 硬证据只留「零推进 + 停机标记」（AC13 ④）。
- **停机率只有 3 条窄用例**读数（E-5 自认测不到「推进了但附带裁决」）（AC13 ⑤）。
- **`shell` 写盘盲区**沿用 v2.41 的登记（权限层不约束 shell）。
- **被派发后端侧不改**（D4）⇒ 后端已有 `HANDOFF: blocked`。
- **另 5 处「必须问用户」声明**未覆盖（design D9）⇒ 登记 + 各自独立 change。
- **本仓 prompt 的行号会随其它 change 漂移** ⇒ 一律按**节标题 + 定位语**引用，**不引用裸行号**。
